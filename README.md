# Pokedex-App

A simple **Pokédex application** built to practice React and TypeScript fundamentals.  
This project was created as an exercise to explore component structure, API integration, and frontend state management.

---

## 🚀 Overview

This app fetches data from an external Pokémon API and displays a list of Pokémon with details such as name, image, and basic stats.  
The goal was to reinforce understanding of:

- React components
- TypeScript types
- API calls (fetch / async)
- Basic UI and responsive layout

---

## 🧠 Key Features

- Fetches Pokémon data from a public API
- Displays a list of Pokémon cards
- Shows basic details for each Pokémon
- Built with TypeScript for type safety
- Responsive layout
